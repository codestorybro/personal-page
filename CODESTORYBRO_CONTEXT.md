# CodeStoryBro — personal brand context

CodeStoryBro is Marcin Kołodziej's professional personal brand.

## Positioning

- Software Developer
- Engineering Manager
- Conference Speaker

The website is a minimal English-language landing page and link hub. It presents professional experience, directs visitors to the active X and LinkedIn profiles, and provides a contact email for conference invitations and professional enquiries.

The brand should feel modern, technical, professional, and personal. It is not positioned as a publication, content project, newsletter, or creator-economy brand.
